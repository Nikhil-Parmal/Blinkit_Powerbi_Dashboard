# Blinkit Grocery Sales Analysis Dashboard | Power BI

## 📌 Project Overview

This project focuses on analyzing Blinkit's grocery sales data using Microsoft Power BI. The objective was to transform raw sales data into meaningful business insights through data cleaning, DAX calculations, and interactive visualizations.

The dashboard provides an overview of sales performance, product categories, outlet characteristics, and customer ratings to help understand business performance across different outlet types and locations.

## 🛠️ Tools & Technologies
- **Power BI:** Dashboard development and data visualization
- **Power Query:** Data cleaning and transformation
- **DAX:** Creating calculated measures and business KPIs
- **Kaggle:** Dataset source

## 📊 Key Performance Indicators (KPIs)

| Metric | Value |
|---|---:|
| Total Sales | ₹1,201,681 |
| Average Sales | ₹140.99 |
| Number of Items | 8,523 |
| Average Rating | 3.92 |

## 🔍 Analysis Performed

**1. Sales Performance Analysis**
- Analyzed total sales and average sales.
- Evaluated overall grocery sales performance.

**2. Fat Content Analysis**
- Compared sales contribution from Low Fat and Regular products.

**3. Item Type Analysis**
- Examined sales distribution across different grocery product categories.
- Identified high-performing product categories.

**4. Outlet Establishment Analysis**
- Analyzed sales trends based on outlet establishment years.

**5. Outlet Size Analysis**
- Compared sales performance across Small, Medium, and High outlet sizes.

**6. Outlet Location Analysis**
- Evaluated sales contribution across Tier 1, Tier 2, and Tier 3 locations.

**7. Outlet Type Analysis**
- Compared outlet types based on:
  - Total Sales
  - Number of Items
  - Average Sales
  - Item Visibility
  - Average Rating

## ⚙️ Key Implementation

- Performed data cleaning and transformation using Power Query.
- Created DAX measures for Total Sales, Average Sales, Number of Items, and Average Rating.
- Implemented Field Parameters to dynamically switch between different KPIs.
- Developed interactive slicers for Outlet Location, Outlet Size, and Item Size.
- Designed interactive charts, KPI cards, and comparative visualizations.

## 💡 Key Business Insights

- Total sales reached approximately ₹1.20 million across 8,523 items.
- Tier 3 outlets generated the highest sales contribution among location tiers.
- Supermarket Type 1 recorded the highest total sales among outlet types.
- Low Fat products contributed approximately 64.73% of total sales.
- Medium-sized outlets represented the largest sales contribution among outlet sizes.

## 🎯 Project Objective

To develop an interactive business intelligence solution that helps stakeholders monitor grocery sales performance, compare outlet effectiveness, and identify important sales trends through data-driven analysis.
